# Learning Electronics

## Overview

This repository documents my journey into electronics, starting with theoretical foundations and progressing towards the design and implementation of a practical electronics project.

The goal is to build a solid understanding of electronic components, circuit analysis, simulation and hardware design before starting the practical project.

## Current Status

**Phase:** Theoretical learning

**Practical project:** Not started

**Main focus:** Understanding the fundamentals of electronics.
